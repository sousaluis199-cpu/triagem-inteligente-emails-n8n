#📧 Triagem Inteligente de E-mails com n8n e #IA

#Sobre o projeto

#Este projeto utiliza o n8n para automatizar etapas da triagem de e-mails recebidos pelo Gmail, com processamento em #JavaScript e integração com um modelo de Inteligência Artificial.

Objetivo

Explorar como a IA pode ajudar a identificar mensagens que exigem atenção prioritária, considerando o contexto, os prazos e as possíveis consequências de atrasos, em vez de depender apenas de palavras-chave como "urgente".

Tecnologias utilizadas

- n8n — automação de workflows
- Gmail — integração com e-mails
- JavaScript — processamento de dados
- Inteligência Artificial — análise contextual, conforme a configuração do workflow

Fluxo de automação

1. Receber e-mails pelo Gmail Trigger.
2. Processar os dados com JavaScript.
3. Aplicar condições de classificação.
4. Encaminhar mensagens conforme as regras configuradas.

Status do projeto

Em desenvolvimento e validação. A classificação contextual de urgência precisa ser testada com diferentes exemplos de e-mails.

Segurança

Credenciais e dados pessoais devem ser mantidos fora do repositório público.

Aprendizados

Este projeto faz parte da minha evolução prática em automação de processos, integração de serviços e Inteligência Artificial.
